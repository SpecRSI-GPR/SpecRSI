\section{Drafter prompt template}
The released \texttt{HFPromptDrafter} uses the following template for task agents represented by a single system instruction. Braced fields are filled at runtime.

\begin{tcolorbox}[
enhanced,
colback=black!5,
colframe=black!75,
colbacktitle=black!75,
coltitle=white,
title={Prompt O1. Drafter for task-agent instructions},
fonttitle=\large\rmfamily,
fontupper=\normalsize,
boxrule=0.5pt,
arc=1.5mm,
left=3mm,
right=3mm,
top=2.5mm,
bottom=2.5mm,
before skip=9pt,
after skip=9pt
]
Write an improved system instruction for the task agent. Return only the new instruction, without commentary. Make a concrete change using the observed feedback; do not copy the current instruction. Preserve the required output format and interface constraints in the current instruction. The checker and evaluation rules cannot be edited.

\medskip
\texttt{\{interface\_guidance\}}

\medskip
\textbf{Current instruction:}\par
\texttt{\{bounded\_parent\}}

\medskip
\textbf{Observed search context:}\par
\texttt{\{context\}}
\end{tcolorbox}
\noindent The feedback serializer includes up to four parent-task examples, with visible task inputs and observed scores, admissibility, and available answer/checker feedback. A null outcome denotes an unobserved result. Examples are selected in failure-first order; task references and metadata are not read. The current instruction and serialized feedback are bounded by the available input-token allowance. The box gives the runtime prompt template used by \texttt{HFPromptDrafter}.
